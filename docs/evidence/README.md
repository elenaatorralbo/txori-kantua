# Evidence

This is where the reports backing acceptance criteria are kept: tables, script
output, measurements and sanitised logs. **Never audio**, credentials, IP
addresses, network names or photos with people.

This directory has no evidence on purpose: no physical test has been run yet.
A report is added when it exists, not before.

## Convention

- One file per test: `YYYY-MM-DD-issue-NN-description.md`.
- Added through a PR linked to the issue (`Refs #NN`) and reviewed by someone
  other than whoever ran the test.
- A simulated test or one done off the Pi says so in its title and **does not
  replace** the physical test.

## Mandatory header of every report

```markdown
- **Date (UTC):**
- **Run by:**
- **Reviewed by:**
- **Issue / PR:**
- **Commit:**
- **Hardware:** (model, OS, architecture)
- **Relevant versions:**
- **Procedure:** (exact commands or link to the document)
- **Expected result:**
- **Observed result:**
- **Limitations and pending tests:**
```
